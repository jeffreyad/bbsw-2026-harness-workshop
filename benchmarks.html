pharma-skills benchmarks

Do agent skills help on clinical data science tasks? A snapshot.

Published

November 5, 2026

Community benchmarks from RConsortium/pharma-skills (R Consortium Submissions Working Group, Pilot 7). Each benchmark issue runs the same task with and without the skill and scores both against a rubric written by the issue author.

Note

This is an informal snapshot compiled from the public issues on November 5, 2026. It is not an official R Consortium summary. Several figures were read from long comment threads, so check the linked issue before quoting a number.

By skill

Mean % of rubric items passed, using the latest scored run per issue (mostly Claude models). W / T / L = skill wins, ties, losses.

Skill With skill Without W / T / L
admiral-adsl 93% 70% 2 / 1 / 0
admiral-adae 100% 67% 2 / 0 / 0
admiral-bds 91% 72% 3 / 0 / 0
admiral-adtte, admiral-adrs 82% 56% 2 / 0 / 0
sdtm-oak 88% 63% 1 / 0 / 0
group-sequential-design 73% 51% 10 / 2 / 3
clinical-trial-simulation 90% 91% 0 / 1 / 1

Pattern: large gains on convention-heavy ADaM and SDTM derivations; little or no gain where the base model already knows the method.

group-sequential-design has its own roll-ups across 15–21 trial-design scenarios:

  • #80: latest run per issue (April 28): 73% vs 51%; 10 wins, 2 ties, 3 losses.
  • #146: best with-skill run per issue (May 31): 90% vs 62%; 16 wins, 4 ties, 1 loss. This picks the skill’s best showing, so treat it as a ceiling.

Caveats

  • Small numbers of runs; rubrics differ by issue and several were tightened and re-scored over time.
  • Runs vary in model, skill version, and date. Results are directional, not a validated comparison.
  • Losses for group-sequential-design were mostly scope gaps (problems outside what the skill covers), not the base model being better.
